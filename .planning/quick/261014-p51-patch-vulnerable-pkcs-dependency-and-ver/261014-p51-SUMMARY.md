# Patch System.Security.Cryptography.Pkcs

Changed: added an explicit `System.Security.Cryptography.Pkcs` 10.0.13 reference
to `src/WorkflowEngine.Infrastructure/WorkflowEngine.Infrastructure.csproj`.
Why: the existing 10.0.0 dependency was flagged for CVE-2026-84008 (High) and
CVE-2026-70162 (Moderate), blocking fresh warning-as-error builds.

## Scope and approach

The existing dependency paths are:

```text
MailKit 4.16.0 -> MimeKit 4.16.0 -> System.Security.Cryptography.Pkcs
EF Core SqlServer 10.0.7 -> Microsoft.Data.SqlClient 6.1.1 -> System.Security.Cryptography.Pkcs
```

Both paths now resolve to 10.0.13. The explicit reference patches an existing
Microsoft dependency at their shared Infrastructure project. MailKit, MimeKit,
EF Core and SqlClient versions stay unchanged. The production diff is two lines:
the reference and a comment recording the two CVEs. No workflow logic, public
contracts, schema, seed, recipient rules, SLA timing or warning/audit policy changed.

The user explicitly authorized this package fix and tests after reviewing the
vulnerability inventory. No further package additions or behavior changes were needed.

Microsoft sources checked on 2026-10-14:
- [High-severity advisory](https://github.com/dotnet/runtime/security/advisories/GHSA-846f-f764-76mx)
