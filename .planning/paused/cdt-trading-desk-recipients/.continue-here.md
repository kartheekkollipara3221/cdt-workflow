- With UI cooperation, no workflow engine code change is necessary: omit notification.recipientInputs.selectedCcUsers entirely on affected actions, and deactivate the corresponding RequestInput rule in SQL.
- Deactivate originalMaker WorkflowParticipant CC rule on affected routes to remove Maker CC. Keep intended static To rules active and preserve assigned-role filtering and at least one To recipient for every supported assignment.
- RouteTradingDeskAssigned is selected by CheckerSendToTradingDesk. Local seed contains Taxable, Tax Exempt and Equity role-filtered static desk AND operations To addresses, plus originalMaker and selectedCcUsers CC.

- Other actions/routes keep their current recipient behavior and UI inputs.
- Task creation snapshots resolved recipients. Initial email and subsequent SLA emails use that snapshot. Existing pending tasks and already queued emails are unchanged by metadata updates.
- WorkflowSeedService.UpsertNotificationRecipientRules sets seeded rows IsActive=true. SQL-only changes could be undone by future reseeding; seed/deployment policy needs alignment before rollout. No seed changes made.
